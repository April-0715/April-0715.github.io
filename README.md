# April-0715's Blog

纯静态个人博客，零构建工具，直接打开即用。

## 目录结构

```
├── css/           样式文件
├── js/            脚本 & 数据
├── articles/      Markdown 文章
├── assets/images/ 本地图片
├── index.html     首页
├── contents.html  文章列表
└── article.html   文章详情
```

## 添加文章

1. 在 `articles/` 下新建 `.md` 文件
2. 在 `js/articles-data.js` 中追加一条元数据

文章列表和首页预览会自动更新。
